# История изменений

## 0.1.7

- добавлена компактная карточка Telegram на главном экране;
- добавлены копирование локального SOCKS5-адреса, проверка порта и быстрый запуск Telegram;
- добавлена безопасная подсказка: ручной прокси нужен только для режима «Локальный прокси», а в VPN-режиме его обычно включать не требуется.

## 0.1.6

- смена профиля на главном экране теперь автоматически перезапускает соединение и применяет новые параметры;
- добавлено понятное уведомление о перезапуске после применения профиля;
- состояние службы сбрасывается при пересоздании Android-сервиса, чтобы старый статус не блокировал повторный запуск.

## 0.1.5

- добавлены профили «Мессенджеры» и «Игровой трафик»;
- улучшена UDP-совместимость консервативным запасом подменных пакетов;
- технические названия компонентов убраны с главного экрана и из уведомлений;
- экспорт диагностики по умолчанию краткий и не включает logcat.

## 0.1.0 — 2026-08-15

- первый выпуск **Zapret Mobile by lolososka**;
- отдельный package ID, поэтому приложение не конфликтует с ByeDPIAndroid;
- новый главный экран в стиле сайта Zapret Control Center;
- локальный VPN-режим без root и без удалённого VPN-сервера;
- режим локального SOCKS5-прокси и редактор параметров стратегии;
- быстрый выключатель Android и системное уведомление;
- русские подписи, светлая и тёмная темы;
- подписанный APK, SHA-256 и соответствующий архив исходного кода в Releases.

Приложение использует движок ByeDPI и основу ByeDPIAndroid. Подробные сведения об авторах и лицензиях находятся в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
